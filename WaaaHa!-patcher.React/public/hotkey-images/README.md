# Иконки хоткеев

Здесь лежат иконки команд. Приложение показывает их в сетке редактора, а поверх
накладывает текущую комбинацию клавиш.

## Как называть файл

Имя файла — **идентификатор хоткея из игры** в нижнем регистре:

```
marine_servitor.png    или    marine_servitor.jpg
chaos_lord.png
marine_hq.png
faction_marine.png     — картинка для кнопки фракции на главном экране
```

Расширение может быть любым из `.png`, `.jpg`, `.webp` — интерфейс перебирает их
по очереди, переименовывать файлы под один формат не нужно.

Список идентификаторов можно посмотреть в любом файле `KEYDEFAULTS*.LUA` из папки
профиля: это имена слева от знака `=` внутри таблицы `bindings`.

## Требования к картинке

- Квадратная, рекомендуемый размер **128×128** (в интерфейсе плитка 62×62, но картинки
  подгружаются в полном размере, поэтому качественное изображение не мылится).
- Формат с прозрачностью — плитка сама рисует рамку и подложку.
- Без выделенного фона: он перекроет тёмную подложку интерфейса.

## Если картинки нет

Ничего страшного: на месте картинки появится клетчатая заглушка с названием
команды. Можно начать с одной фракции и добавлять остальные постепенно.

## Как скачать иконки с вики

В репозитории есть скрипт, который берёт картинки со страницы фракции на
warhammer-guide.ru, сопоставляет их с идентификаторами и кладёт сюда:

```
node tools/fetch-wiki-icons.mjs --faction=marine
```

Сопоставления лежат в самом скрипте (`FACTION_ICONS`). Заведён только космодесант —
скрипт печатает оставшиеся картинки страницы, чтобы их можно было добавить.

Картинки с вики помечены водяным знаком Relicnews и не квадратные: обрезку и размер
предполагалось доделать позже.

## Как проверить, что всё подхватилось

1. Запустить приложение.
2. Открыть профиль и любой набор.
3. Выбрать фракцию и посмотреть на сетку.
