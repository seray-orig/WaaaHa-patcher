# Иконки хоткеев

Здесь лежат иконки команд. Приложение показывает их в сетке редактора, а поверх
накладывает текущую комбинацию клавиш.

Иконки вытащены из ресурсов самой игры: они крупнее и чётче, чем картинки с
вики, и это их настоящие значки — те, что игрок видит на панели.

## Как называть файл

Имя файла — **идентификатор хоткея из игры** в нижнем регистре:

```
marine_servitor.png    или    marine_servitor.jpg
chaos_lord.png
marine_hq.png
faction_marine.png     — картинка для кнопки фракции на главном экране
```

Расширение может быть любым из `.png`, `.jpg`, `.webp` — интерфейс перебирает их
по очереди, переименовывать файлы под один формат не нужно.

Список идентификаторов можно посмотреть в любом файле `KEYDEFAULTS*.LUA` из папки
профиля: это имена слева от знака `=` внутри таблицы `bindings`.

## Требования к картинке

- Квадратная, **128×128**. В интерфейсе плитка 62×62, этого хватает с запасом
  для Retina. Иконки из игры бывают 256×256 — их обязательно нужно уменьшать,
  иначе репозиторий тяжелеет вчетверо без видимой разницы на экране.
- Формат с прозрачностью — плитка сама рисует рамку и подложку.
- Без выделенного фона: он перекроет тёмную подложку интерфейса.

## Если картинки нет

Ничего страшного: на месте картинки появится клетчатая заглушка с названием
команды. Иконка не пропадает, даже если хоткей снят клавишей Delete — сняли клавишу,
команда никуда не делась.

## Как обновить иконки из ресурсов игры

Распакованные `.rtx` складываются в папку с `manifest.csv` и двумя каталогами
`PNG` и `JPEG`. Дальше:

```
powershell -ExecutionPolicy Bypass -File tools/update-icons.ps1 "C:\файлы2"
```

Скрипт копирует картинки и уменьшает их до 128×128. Порядок важен: сначала
копирование, потом уменьшение, иначе вернутся исходники.

Сопоставление «идентификатор хоткея → файл в игре» лежит в
`tools/game-icon-map.mjs`. Имена в игре свои: `spacemarine_icon` это
`marine_space_marine`, `attackm` это `attackmove`, `guard_squad_guardsmen` это
`guard_guardsmen`. Совпадений мало, поэтому таблица ведётся руками; там же
указано, из какой папки брать иконку, когда одноимённые лежат у нескольких рас.

Иконки, которым в игре соответствует несуществующий в `KEYDEFAULTS.LUA`
идентификатор, скрипт удаляет: показывать картинку команды, которой нет, —
значит врать игроку.

## Как скачать иконки с вики

Запасной путь: скрипты ходят на страницы юнитов и берут оттуда квадратную
иконку 64×64 из блока «Build Info». Картинки со страницы фракции не годятся:
там большие фотографии отрядов 300×150, а нужны иконки отдельных юнитов.

```
node tools/fetch-faction-icons.mjs                  все расы
node tools/fetch-faction-icons.mjs --faction=eldar  одна раса
node tools/fetch-ability-icons.mjs                  умения космодесанта
node tools/fetch-weapon-icons.mjs                   выдаваемое оружие
```

Сопоставление «страница вики → идентификатор хоткея» лежит в
`tools/faction-pages.mjs`.

## Чего нет нигде

Общие команды панели (stop, move, attackmove, attackmelee, build, repair, rally,
reinforce и прочие) на вики отсутствуют совсем, но в ресурсах игры они есть —
в папке `command_icons`, и теперь подхватываются автоматически.

Иконку не удалось найти для `sisters_battle_standard` и
`marine_furious_charge_research`: в игре для этих умений значка нет. На их месте
показывается текстовая заглушка.

## Как проверить, что всё подхватилось

1. Запустить приложение.
2. Открыть профиль и любой набор.
3. Выбрать фракцию и посмотреть на сетку.
