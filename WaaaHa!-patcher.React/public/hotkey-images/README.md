# Иконки хоткеев

Здесь лежат иконки команд. Приложение показывает их в сетке редактора, а поверх
накладывает текущую комбинацию клавиш.

## Как называть файл

Имя файла — **идентификатор хоткея из игры** в нижнем регистре:

```
marine_servitor.png    или    marine_servitor.jpg
chaos_lord.png
marine_hq.png
faction_marine.png     — картинка для кнопки фракции на главном экране
```

Расширение может быть любым из `.png`, `.jpg`, `.webp` — интерфейс перебирает их
по очереди, переименовывать файлы под один формат не нужно.

Список идентификаторов можно посмотреть в любом файле `KEYDEFAULTS*.LUA` из папки
профиля: это имена слева от знака `=` внутри таблицы `bindings`.

## Требования к картинке

- Квадратная. Вики отдаёт 64×64, для своих лучше брать **128×128**: в интерфейсе
  плитка 62×62, и качественная картинка не мылится.
- Формат с прозрачностью — плитка сама рисует рамку и подложку.
- Без выделенного фона: он перекроет тёмную подложку интерфейса.

## Если картинки нет

Ничего страшного: на месте картинки появится клетчатая заглушка с названием
команды. Иконка не пропадает, даже если хоткей снят клавишей Delete — сняли клавишу,
команда никуда не делась.

## Как скачать иконки с вики

Скрипты ходят на страницы юнитов и берут оттуда квадратную иконку 64×64 из блока
«Build Info». Картинки со страницы фракции не годятся: там большие фотографии
отрядов 300×150, а нужны иконки отдельных юнитов.

```
node tools/fetch-faction-icons.mjs                  все расы
node tools/fetch-faction-icons.mjs --faction=eldar  одна раса
node tools/fetch-ability-icons.mjs                  умения космодесанта
node tools/fetch-weapon-icons.mjs                   выдаваемое оружие
```

Сопоставление «страница вики → идентификатор хоткея» лежит в
`tools/faction-pages.mjs`. На вики имена другие: «Cultist Squad» это
`chaos_cultist`, «Gretchin» это `ork_grots`, а «Plasma Generator» у каждой расы
свой — поэтому сопоставление приходится вести руками.

Иконкой вкладки фракции ставится командир расы: форс-командер, демон-принц,
команд-сквад, эфиреал, фарсиер, некрон-лорд, архонт, варбосс, канонисса.

Скачанные иконки — 64×64 и сжатые; обрезку, увеличение и пережатие в PNG
предполагалось доделать позже.

## Чего на вики нет

У части техники и построек страницы с иконкой не существует, а на странице фракции
у них только фотография. Скрипт такие случаи печатает списком в конце работы —
это и есть список того, что придётся нарисовать или положить руками:

```
shas.27Ui_Bodyguard  →  tau_fire_warrior_shasui
Pile_O_Gunz.21      →  ork_pile_o_guns
Da_Listenin.27_Post →  ork_listening_post
Waaagh.21_Banner    →  ork_waagh_banner
tau_hammerhead
tau_shrine_of_montka
```

Общие команды — stop, move, attackmove, attackmelee, build, repair, rally,
reinforce — на вики отсутствуют совсем: их рисует сама игра.

## Как проверить, что всё подхватилось

1. Запустить приложение.
2. Открыть профиль и любой набор.
3. Выбрать фракцию и посмотреть на сетку.
